# Weather Web Scraping Capstone

## Project Overview

This project collects weather data from the Weather Around The World website using Selenium. The scraped data is cleaned using Pandas and saved to a CSV file for further analysis.

The final capstone project will store the data in a SQLite database and display interactive visualizations using Streamlit.

## Data Source

https://www.timeanddate.com/weather/
